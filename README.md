## 🚀 About
This is an interactive **Owl AI** internship website created to showcase the organization's mission, internship tasks, and certification process. It includes engaging interactive elements, themed styling, and responsive design for all devices.

---

## ✨ Features
- **Responsive Design** – Desktop, tablet, and mobile friendly.
- **Interactive Elements** – Buttons, hover effects, and smooth scrolling.
- **Sections**:
  - About Owl AI
  - Internship Program (3-task certification)
  - Task Details (Simple Task 1, 2, Hard Task)
  - Sample Certificate Preview
  - Apply Section (Call-to-action)
- **Creative Touches** – Owl-inspired styling for a fun, unique look.
